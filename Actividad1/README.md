# Actividad 1 - Programación Web

Repositorio de ejercicios de la unidad 2, de la materia de programación web

Elaborados por Karla Guadalupe Antonio Vázquez

# Contenido

En este repositorio se encuentran diferentes ejercicios realizados durante la materia de Programación Web, con la finalidad de poner en práctica los conocimientos aprendidos sobre el desarrollo de páginas web. A través de estas actividades se trabaja principalmente con HTML, aprendiendo a utilizar sus diferentes etiquetas y elementos para crear y organizar contenido.

Cada ejercicio permite practicar de una manera diferente la estructura de una página web, desde la creación de contenido básico hasta la organización de información dentro de un documento HTML. Con estas actividades se busca reforzar los conocimientos adquiridos y familiarizarse poco a poco con el desarrollo web.

## Ejercicios

### **Ejercicio 1 — Mi Primera Página HTML ("Hola Mundo")**
Crear una página HTML básica con la estructura mínima de HTML5 (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`) que muestre el mensaje "¡Hola Mundo!", alojada en el servidor local XAMPP.

### **Ejercicio 2 — Párrafos y Formato Básico**
Practicar etiquetas de texto: `<p>` para párrafos, `<strong>` para negrita semántica, `<em>` para énfasis/cursiva, y `<br>` para saltos de línea.

### **Ejercicio 3 — Enlaces Simples**
Crear hipervínculos con `<a href="">`, usando `target="_blank"` (nueva pestaña) y `target="_self"` (misma pestaña), enlazando a sitios externos y de vuelta al ejercicio 1.

### **Ejercicio 4 — Imágenes Básicas**
Insertar una imagen con `<img>`, usando los atributos `src` (ruta), `alt` (texto alternativo) y `width` (ancho), alojando el archivo en la carpeta `img/`.

### **Ejercicio 5 — Combinando Texto y Enlaces**
Integrar lo aprendido: colocar una `<img>` dentro de un `<p>` y crear un enlace `<a>` con URL absoluta y texto descriptivo (página tipo "blog personal").

### **Ejercicio 6 — Secciones Semánticas Básicas**
Usar etiquetas semánticas de estructura: `<header>` (cabecera), `<section>` (contenido agrupado) y `<footer>` (pie de página).

### **Ejercicio 7 — Listas Anidadas + Enlaces**
Crear una página de receta ("Tacos al Pastor") usando listas ordenadas (`<ol>`) y desordenadas (`<ul>`), incluyendo una lista anidada dentro de otra.

### **Ejercicio 8 — "Horario de Clases"**
Diseñar un horario semanal usando tablas (`<table>`, `<tr>`, `<td>`, `<th>`, `<thead>`, `<tbody>`), incluyendo `rowspan`/`colspan` y estilizado con un archivo CSS externo.

### **Ejercicio 9 — Formulario de Contacto**
Construir un formulario accesible y estilizado con `<form>`, `<fieldset>`, `<label>`, distintos tipos de `<input>` (text, email, tel), `<textarea>` y botón de envío, aplicando CSS externo (variables `:root`, grid, box-sizing, etc.).

### **Ejercicio 10 — Calculadora de Celsius a Fahrenheit (JS)**
Desarrollar una calculadora con HTML y JavaScript: el usuario ingresa grados Celsius, presiona "Convertir", y el resultado en Fahrenheit se muestra en un campo `readonly` (fórmula F = C×9/5 + 32), con validación de que el campo no esté vacío y sea numérico.
